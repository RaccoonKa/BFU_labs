# Fundamentals of Python

An educational course on the basics of the Python programming language. Built around hands-on lab assignments that cover the core language constructs: from input and conditional statements to loops, strings, functions, and data structures.

## What the course is about

Python is a general-purpose programming language valued for its readable syntax and wide ecosystem. The course walks through the fundamental building blocks of the language through small, practical tasks: reading and processing input, controlling program flow, manipulating strings, and working with lists, dictionaries, and functions.

**Input and conditionals.** Every program starts with data: reading values from the user with `input()` and converting them to the right types with `int()` or `float()`. Conditional statements (`if` / `elif` / `else`) and logical operators (`and`, `or`) let a program branch depending on its data — for example, finding the maximum and minimum of three numbers.

**Loops and pattern output.** `for` and `while` loops drive repetition. Nested loops produce structured output such as staircases and number triangles, while the Pascal's triangle task combines loops with list arithmetic. The Sierpiński-style pattern demonstrates recursive generation and string padding.

**Strings.** Strings are immutable sequences with a rich set of methods (`isalpha()`, `isdigit()`, `replace()`, slicing). Lab tasks cover run-length encoding (compressing repeated characters into `char + count` form) and the reverse operation (expanding `char + count` back into repeated characters).

**Dictionaries and functions.** Dictionaries map keys to values and are used to build a lookup table that spells out numbers from 1 to 1000 in Russian, and to count word occurrences in a list. Functions (`def`) let logic be reused and composed — demonstrated by abbreviation generation from the first letters of words and by checking the linear dependence of matrix columns via a 3×3 determinant.

**Lists and matrices.** Lists are ordered, mutable collections. They represent sequences of words and rows of a matrix, and support iteration, indexing, and comprehensions for concise construction.

## Course structure

| # | Topic | Key constructs |
|---|-------|----------------|
| 1 | Input, conditionals, max/min of three numbers | `input()`, `int()`, `if`/`elif`/`else`, `and` |
| 2 | Loops and pattern output (staircase, Pascal's triangle, fractal) | `for`, `while`, nested loops, `range()`, `join()`, `center()` |
| 3 | String compression and expansion | `isalpha()`, `isdigit()`, slicing, `replace()`, `while` |
| 4 | Dictionaries: numbers to text, word counting | `dict`, `.split()`, `.items()` |
| 5 | Functions: abbreviation, matrix linear dependence | `def`, list comprehensions, determinant |
