# Operating Systems and Computer Networks

An educational course combining the fundamentals of OS administration with hands-on work on network protocols. The materials include lab assignments on network diagnostics, topology modeling, and interaction with web services.

---

## What the course is about

The course is built around a practical understanding of how a network works at different levels — from the Windows command line to emulated routers and HTTP requests.

**Diagnostics and utilities.** The first block covers basic network utilities (`ping`, `tracert`, `ipconfig`, `netstat`, `nslookup`, `arp`, `pathping`). Students learn to read the output, analyze routes, check DNS, and understand the difference between tracing tools.

**Wireless networks.** A separate assignment is dedicated to Wi-Fi spectrum analysis: channel visualization, signal strength assessment (dBm), selection of free frequencies, and understanding congestion in the 2.4 GHz and 5 GHz bands.

**Network modeling.** Using Cisco Packet Tracer, students build topologies (PCs, switches, routers), configure interfaces, set up dynamic routing (RIP) and DHCP. Special attention is paid to security — implementing ARP spoofing and analyzing ARP tables.

**Application layer.** The final assignment is interaction with web services via Python (`requests`): sending OPTIONS, GET, and POST requests, analyzing headers and response bodies, working with parameters and JSON.

**Outcome.** The course provides an end-to-end understanding: from how the OS configures a network interface to how an application sends an HTTP request and receives a response.
