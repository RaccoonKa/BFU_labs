# Algorithms and Data Structures

An educational course covering the fundamental algorithms and data structures that form the backbone of efficient programming. The materials include lab assignments on complexity analysis, sorting, searching, and working with core data structures.

## What the course is about

The course is built around a practical understanding of how algorithms and data structures affect performance and how to choose the right tool for a given task.

**Complexity analysis.** Students learn to evaluate algorithms by time and space complexity, understand asymptotic notation (O, Ω, Θ), and recognize common growth patterns in real code.

**Sorting and searching.** Lab assignments cover classical sorting algorithms (bubble, insertion, merge, quick) and binary search, with hands-on comparison of their performance on different input sizes.

**Core data structures.** The course explores arrays, linked lists, stacks, queues, hash tables, and trees, focusing on when to use each and how their implementation choices impact efficiency.

**Practical implementation.** Students implement algorithms and data structures in code, test edge cases, and analyze trade-offs between simplicity, speed, and memory usage.

**Outcome.** The course provides a solid foundation for writing efficient code and understanding how algorithmic decisions ripple through real-world applications.
